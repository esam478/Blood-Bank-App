# 🩸 تطبيق بنك الدم (Blood Bank App)

تطبيق ويب متطور (PWA) يهدف إلى تسهيل عملية التواصل بين المتبرعين والمحتاجين لفصائل الدم بشكل سريع وفعال.

## ✨ مميزات التطبيق:
* **تثبيت مباشر:** يمكن تثبيته على شاشة الهاتف كأي تطبيق حقيقي بدون متجر.
* **يعمل بدون إنترنت:** بفضل تقنية الـ Service Worker.
* **واجهة عربية:** تصميم بسيط وسهل الاستخدام للجميع.

## 🚀 كيف تثبت التطبيق؟
1. افتح رابط التطبيق في المتصفح.
2. من خيارات المتصفح، اختر **"إضافة إلى الشاشة الرئيسية"**.
3. سيظهر التطبيق الآن بجانب تطبيقاتك الأخرى.
